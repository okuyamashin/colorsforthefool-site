    Kulay na lapis

    Sa ngipin ng papel, libo-libong maikling hagod ang bumubuo ng balat. Ang mga uka ng sungay, ang mga tupi ng pulang tela, ang ginto ng tanikala: lahat ay bakas ng iisang ubod ng lapis. Gumuguhit ng bilog ang isang bituin sa sahig. Nakayuko ang mga mukha ng dalawang pigura. Nanatili ang alikabok ng lapis, manipis, sa labas mismo ng balangkas, sa hugis ng isang daliri. Sundan ang direksyon ng isang hagod, at lumilipat ang ubod ng lapis sa papel sa panig ninyo, at nagsisimula ng balangkas ng isang lalamunan sa parehong diin.
